A tiny Node program that writes one sentence to `/output/entry.txt` — an explanation of the modern internet for a traveler arriving from 1800, built only from things they already know: libraries, roads, letters, ink. Every library in the world joined by roads so fast a letter crosses the earth before the ink is dry, and anyone may read or write in any of them. 174 characters, deterministic, no network.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts && cat ./out/entry.txt
```
